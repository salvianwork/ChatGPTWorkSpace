# File wajib untuk dikirim ke client

Kirim kedua workbook berikut kepada client:

1. `01_REVIEW_CLIENT_SEDERHANA.xlsx` — file utama. Client mengisi 14 keputusan kelompok dan mencatat pengecualian jika ada.
2. `02_REVIEW_CLIENT_DATA_REGIONAL.xlsx` — rincian lengkap. Client membukanya hanya jika ingin memeriksa record tertentu atau contoh tambahan.

Client tidak perlu menerima `MAPPING_ID_INVALID_KE_VALID.xlsx` pada tahap review awal. File tersebut digunakan oleh tim data setelah keputusan client diterima.
